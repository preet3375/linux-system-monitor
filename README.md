# Linux System Monitor

A Linux system monitoring tool written in C++ using the Linux `/proc` filesystem.

## Current Features

- Memory usage monitoring
- Total memory
- Available memory
- Used memory
- Memory usage percentage

## Planned Features

- CPU usage monitoring
- Process monitoring
- Disk usage monitoring
- Network monitoring
- Interactive terminal interface

## Technologies

- C++
- Linux
- `/proc` filesystem
- Git
- GitHub
